# ✦ Vexa – Your AI. Your way.

> A MERN-based AI chat application built from scratch using OpenAI — reimagined with a Gemini-inspired UI.

## Tech Stack
- **Frontend:** React + Vite, CSS Variables, Font Awesome
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **AI:** OpenAI API

## Setup
1. Clone the repo
2. Add `.env` in `/Backend` with `MONGODB_URI` and `OPENAI_API_KEY`
3. `cd Backend && npm install && node server.js`
4. `cd Frontend && npm install && npm run dev`
